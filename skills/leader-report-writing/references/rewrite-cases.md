# 改写案例（脱敏，仅保留句式结构）

## 案例一：太虚 → 实

**原稿**（领导反馈：太虚了）
> 依托现有系统存量市场基础与运维场景积累，推动系统与智能助手深度融合，打造"系统＋助手＋工作流"一体化运营方案——助手承接告警筛选、异常识别、任务跟踪等执行工作，智能问数与报告生成替代低价值重复劳动，从"人盯界面"转向"助手值守、人聚焦异常处置与决策"，形成友商难以复制的差异化能力，提高竞争门槛。

**问题**：通篇是机制与愿景，没有任何可验收的东西；"融合""一体化""赋能"删掉后句子为空。

**改后**
> 上季度完成智能诊断模块（版本 X）发版并打通业务系统链路，重点机型 TOP100 高频场景知识全覆盖；建成运行值守助手基础功能，落地设备异常分析、能耗时机提醒等场景。下季度展望：推进全链路试运行，重点场景采纳率达 80%；值守助手扩展异常停机、功率受限等异常发现与跟踪督办场景。

**改了什么**：
- 机制词 → 交付物（发版、打通链路、全覆盖、落地场景）
- 愿景 → 量化目标（采纳率 80%）
- 抽象场景 → 具体枚举（异常停机、功率受限）
- 价值句压缩为段尾一句，且不出现空洞形容词

## 案例二：太细 → 目标

**原稿**（领导反馈：太具体，缺少目标性，读不懂）
> ①流程引擎产品化：以智能流程为支撑，实现业务流程预置编排、在线配置与实例化执行，节点由助手自动执行或人机协同完成；②形成面向存量客户的标准解决方案，与集控、生产管理系统深度集成；③按灰度策略扩展故障降噪、异常停机分析、功率监测、温度告警、端到端督办等场景，落地 A、B 两类工作流。

**问题**：全是落地动作和技术实现；没有一条说"达成什么"。

**改后**
> ①完成平台与知识库初版迭代，支撑场景快速装配与复用；
> ②完成异常停机、功率受限等异常发现与跟踪督办，能耗调度等主动分析场景落地，推进试点验证见效；
> ③提供面向销售与解决方案的销售材料（存量、新签场景方案及 BOM），支撑售前引导与新签转化。

**改了什么**：
- 技术实现 → 目标与价值（"流程引擎产品化"→"支撑场景装配复用"）
- 删掉"深度集成""实例化执行""灰度策略"等术语
- 每条补一个可验收靶子（初版迭代 / 场景落地 / 材料发布）

## 案例三：太长 → 简

**原稿**
> 完成异常停机、功率受限等运行异常发现与问题跟踪督办，储能充放电、设备主动限电等主动分析场景落地，推进试点验证见效。

**改后**
> 完成异常停机、功率受限等异常发现与跟踪督办，能耗调度等主动分析场景落地。

**改了什么**：
- 并列场景取代表性两项，其余归入大类词
- 删"问题""运行""设备主动"等修饰
- 删冗余尾巴（"推进试点验证见效"在已说明场景落地后属重复）

## 案例四：表格行对齐

**同表其它行的写法**
> ①发布标准 3 类场景化方案，匹配不同客户需求痛点
> ②与关键供应商建立战略合作及签订框架，构建渠道和成本优势
> ③统一 BOM、安装调试标准和验收清单，支撑批量销售交付

**提取到的句式特征**
1. 动词开头（发布 / 与…建立 / 统一）
2. 带数量或括号内场景（3 类、BOM、安装调试标准）
3. 价值短语收尾（匹配…、构建…、支撑…）

**套用后的新行**
> ①完成平台与知识底座初版迭代，支撑场景快速装配与复用
> ②完成异常发现与跟踪督办、主动分析等场景落地，推进试点验证见效
> ③提供面向销售的销售材料（存量、新签场景方案及 BOM），支撑售前引导与新签转化

**要点**：句式对齐 > 句子漂亮。三条分别对应能力 / 业务 / 交付支撑，领导一眼看出这段覆盖了什么。
