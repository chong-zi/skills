# PPT演示串词生成器

## 概述

本技能用于生成功能讲解类PPT的演示串词，帮助用户快速撰写专业、结构化的演示讲解稿。适用于技术方案介绍、产品功能讲解、平台特性展示等场景。

## 使用场景

当用户提出以下需求时，应使用本技能：
- "帮我生成PPT演示串词"
- "写一段演示讲解稿"
- "为这个PPT写演讲稿"
- "生成功能介绍的串词"
- 提供PPT截图或内容，要求生成讲解文案

## 工作流程

### 1. 收集输入信息

需要从用户处获取：
- **参考风格**（可选）：用户提供的参考文本或行文风格要求
- **PPT内容**：PPT截图、文字描述或要点列表
- **目标受众**：技术人员、管理层、客户等
- **演示时长**（可选）：影响串词的详细程度

### 2. 分析PPT结构

识别PPT中的核心要素：
- 标题和主题
- 核心功能/特性列表
- 技术架构图
- 数据指标
- 应用场景

### 3. 生成演示串词

按照以下结构生成：

**a) 开篇引入**（1-2段）
- 点明方案/平台的目标和核心价值
- 说明面向的需求或痛点
- 提出解决方案的核心思路

**b) 核心能力介绍**（多段，每个功能/特性一段）
- 使用"**标题**"开头，突出重点
- 说明具体能力和实现方式
- 体现用户价值或技术优势
- 使用量化数据或具体场景增强说服力

**c) 总结收尾**（1段）
- 总结整体价值和应用效果
- 强调差异化优势或竞争壁垒
- 展望未来发展方向（可选）

### 4. 优化和调整

根据用户反馈进行调整：
- 调整详细程度
- 修改行文风格
- 补充或删减内容
- 生成简版（用于PPT备注）

## 行文风格要点

参考 `references/writing-style.md` 中的详细指南，核心要点：

1. **简洁有力**：避免冗长表述，直击要点
2. **逻辑清晰**：按照"问题-方案-价值"的逻辑展开
3. **突出价值**：从用户角度体现好处和效果
4. **数据支撑**：使用量化指标增强说服力
5. **专业表达**：使用行业术语，体现专业性

## 输出格式

生成的演示串词应：
1. 保存为 Markdown 格式文档
2. 使用清晰的标题层级
3. 使用加粗突出关键词
4. 段落之间留有适当空白
5. 可选：同时生成简版（一句话版本）用于PPT备注
